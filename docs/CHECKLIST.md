# Checklist de entregables EP3

Evaluación Parcial 3 (40 %), DSY1104 Desarrollo Full Stack II. Autor: Dinko Ocampo.

## Entregables

- [ ] Enlace al repositorio público del backend (casas-embrujadas-api)
- [ ] Enlace al repositorio público del frontend (casas-embrujadas-frontend)
- [ ] Backend comprimido (.zip, sin target/ ni .env)
- [ ] Frontend comprimido (.zip, sin node_modules/ ni .env)
- [ ] Documento ERS terminado
- [ ] Manual de usuario con pantallazos
- [ ] Documentación de APIs (Excel, Anexo 3)
- [ ] Documento de APIs e Integración (Word, Anexo 2)
- [ ] Presentación de 15 minutos con demo de los tres roles

## Requisitos de la pauta

### Backend

- [ ] Proyecto Spring Boot con dependencias de base de datos y seguridad
- [ ] MySQL conectado desde el backend
- [ ] Entidades, relaciones, repositorios y services
- [ ] Lógica de negocio encapsulada y con pruebas
- [ ] Controladores REST con CRUD y rutas versionadas
- [ ] Swagger documentando los endpoints

### Seguridad

- [ ] Spring Security con autenticación por roles
- [ ] JWT
- [ ] ADMINISTRADOR con acceso total
- [ ] VENDEDOR solo ve lista y detalle de productos y de boletas, en frontend y backend
- [ ] CLIENTE solo accede a la tienda

### Integración

- [ ] El frontend consume la API con axios
- [ ] Manejo de datos y errores en cada vista

### Repositorios

- [ ] Commits claros y coherentes
- [ ] README en ambos repositorios
- [ ] FUENTES.md con lugares, leyendas, imágenes y audio

## Funciones extra

- [ ] Favoritos
- [ ] Comparador
- [ ] Mapa
- [ ] Dashboard
- [ ] Boleta en PDF
